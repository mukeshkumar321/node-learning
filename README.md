# Node.js Interview Preparation

A focused Node.js interview preparation guide for backend developers with
approximately three years of professional experience.

This repository covers the core Node.js, Express.js, API, security, database,
error-handling, and performance topics expected in a 3 YOE interview.

## Recommended Study Order

1. Learn the Node.js runtime and event loop.
2. Practice callbacks, promises, and `async/await`.
3. Understand modules, npm, and package management.
4. Build APIs with Express.js and HTTP fundamentals.
5. Study authentication, authorization, and common security risks.
6. Review database access, transactions, indexes, and query optimization.
7. Practice reliable error handling and graceful shutdown.
8. Finish with performance, caching, streams, workers, and scaling.

## Interview Preparation Focus

For every chapter, prepare:

- Definitions and clear mental models
- Internal working and important trade-offs
- Short code examples
- Common mistakes and debugging scenarios
- Project-based follow-up questions
- Practical 3 YOE interview questions
